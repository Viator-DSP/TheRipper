# TheRipper

### Concept:
A free alternative to Soundtoy's Decapitator with 
some cooler features and more distortion modes. 

### List of DSP Features:
- Modes: Class D Amp, Tape Machine, Hard Clipper, Multiple Tube modes (triode and pentode?), Overdrive, Circle Map
- HP and LP filters
- Tone control (tilt)
- Thump (low bump above the HP cutoff)
- Rip (+18 DB on input)
- Steep (slope of filters)
- Auto Gain
